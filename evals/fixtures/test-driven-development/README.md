# 分期付款

将一定数额的钱分出去的用途 `n` 参与者无
损失或发明美分。
库从不触及浮动点。

## API

`splitCents(totalCents, n)` 返回数组 `n` 整数
`totalCents` 是一个非负整数, `n` 是一个正整数。

## 变化因素

每项结果必须满足两种变化因素,每一投入:

1. **准确性** ——股份总和准确到. `totalCents`钱永远不会
   丢失或创建。
2. **公平性** ——无两股差异大于1美分.
    总和不均匀, 剩下的分数要到最早
   股份,每股一分钱。

举例来说, `splitCents(100, 7)`  为: `[15, 15, 14, 14, 14, 14, 14]`.
