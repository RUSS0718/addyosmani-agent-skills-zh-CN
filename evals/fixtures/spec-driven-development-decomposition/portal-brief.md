# 客户门户-产品简介

领导者想要一个自我服务客户门户作为一项举措运出。
请求,如上所述:

- 客户签入 email/password 或公司 SSO 并管理其
  账户和团队成员。
- 客户选择计划,输入付款细节,并每月收到发票;
  计划中的调整按比例进行。
- 客户收到发票、付款失败和团队邮件通知
   请柬; 企业客户可以为同一事件注册网约车。
- 管理者看到一个使用仪表板:座椅, API 和每个月的花费。

迄今存在的制约因素:

- 计费必须知道客户是谁,所以取决于账户数据.
- 通知开户和开户事件失火.
-  该仪表板从账单和通知交付记录中读取。
-  这四个领域有不同的审查者: 平台拥有账户,财务
  拥有计费,增长 拥有通知和仪表板。
- 每一地区应可自行装运和可核查;资金要
   不等仪表板就签收帐单
