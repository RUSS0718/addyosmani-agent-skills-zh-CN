description: Conduct a five-axis code review — correctness, readability, architecture, security, performance
---

调用代理技能:code-review-and-quality 技术。

 审查目前的变动 (已实施或最近实施) 跨越所有五个轴线:

1. **正确性** 符合规格吗 处理的边缘案件 测试是否充分
2. ** 可读性** - 清点姓名 直截了当的逻辑 组织良好
3. **建筑** 遵循现有的模式 干净的界限 正确的抽象水平 ?
4. **警卫** - 输入验证 保密? (使用( U) security-and-hardening 技能)
5. **业绩**  没有N+1查询?没有未绑定的操作? (使用( U) performance-optimization 技能)

将调查结果归类为关键、重要或建议。
提供附有具体文件的结构化审查:线性参考书目和固定建议。
