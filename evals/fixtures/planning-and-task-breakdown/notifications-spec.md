# 通知规格

 当任务被指定或成为时,用户可以选择使用电子邮件通知
过期。 每个用户存储首选项, 默认为禁用 。 指派
事件已经存在;逾期检测每15分钟一次。

所需经费:

- 添加首选项 read/update 带有边界验证的终点。
-  从派任和逾期流中公布通知工作。
-  按用户、任务、事件类型和事件版本分列的重复任务。
-  通过现有的提供者适配器发送电子邮件 。
- 记录发送状态而不存储信件机构 。
- 特性标记发送路径; 禁用仍然是安全默认 。

核查必须包括优先性 API 测试,工作重复测试,
提供方-适应方整合测试,以及一个端到端任务方案。
 没有短信、按下通知或通知历史 UI 属于范围。
